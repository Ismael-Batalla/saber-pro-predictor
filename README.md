##  Descripción del proyecto

**Saber Pro Predictor** es un sistema inteligente desarrollado mediante técnicas de Machine Learning, cuyo propósito es analizar información académica y realizar predicciones relacionadas con el rendimiento de los estudiantes en las pruebas Saber Pro en Colombia.

El proyecto integra técnicas de análisis y procesamiento de datos, entrenamiento de modelos predictivos y evaluación de resultados para construir una herramienta que facilite la interpretación de información académica.

Además, cuenta con una aplicación web desarrollada con **Streamlit**, mediante la cual los usuarios pueden interactuar con el sistema, realizar predicciones y consultar los resultados obtenidos por los modelos.

##  Objetivo general

Desarrollar un sistema basado en técnicas de Machine Learning que permita analizar y predecir el rendimiento académico de los estudiantes en las pruebas Saber Pro, utilizando información y variables relacionadas con su contexto académico.

##  Funcionalidades principales

- **Análisis exploratorio de datos:** identificación de características, patrones y relaciones presentes en los datos.
- **Preprocesamiento:** preparación y transformación de los datos para su utilización en los modelos de Machine Learning.
- **Entrenamiento de modelos:** implementación de algoritmos de aprendizaje automático para realizar predicciones.
- **Evaluación de modelos:** análisis del desempeño de los modelos mediante métricas de evaluación.
- **Predicción del rendimiento:** generación de resultados predictivos a partir de la información suministrada.
- **Aplicación web:** interfaz interactiva construida con Streamlit para facilitar el uso del sistema.
- **Interpretación de resultados:** presentación de las predicciones para facilitar su comprensión.

## 🚀 Instalación y ejecución

### 1. Clonar el repositorio

```bash
git clone https://github.com/Ismael-Batalla/saber-pro-predictor.git
```

### 2. Ingresar al proyecto

```bash
cd saber-pro-predictor
```

### 3. Crear un entorno virtual

```bash
python -m venv venv
```

Activar el entorno virtual en Windows:

```bash
venv\Scripts\activate
```

En Linux o macOS:

```bash
source venv/bin/activate
```

### 4. Instalar las dependencias

Si el proyecto incluye un archivo `requirements.txt`:

```bash
pip install -r requirements.txt
```

### 5. Ejecutar la aplicación

Desde la carpeta que contiene el archivo principal de Streamlit:

```bash
streamlit run nombre_del_archivo.py
```


##  Aplicación y resultados

La aplicación web permite interactuar con el sistema de predicción y consultar los resultados generados a partir de los modelos entrenados.

El propósito es proporcionar una herramienta de apoyo al análisis del rendimiento académico, aprovechando las capacidades del aprendizaje automático para identificar patrones y generar estimaciones.

##  Contexto académico

Este proyecto se desarrolla en el contexto de la formación en Ingeniería de Sistemas, integrando conocimientos de:

##  Consideraciones

Las predicciones generadas por el sistema son estimaciones basadas en los datos y modelos utilizados durante su entrenamiento. Por tanto, no representan resultados oficiales del ICFES ni garantizan el desempeño real de un estudiante.

El sistema tiene fines académicos, experimentales y de apoyo al análisis de datos.
